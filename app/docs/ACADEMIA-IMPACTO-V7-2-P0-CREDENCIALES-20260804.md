# ACADEMIA — Impacto V7.2 P0 credenciales

**Fecha:** 2026-08-04

## Impacto

No cambia cursos, rutas por rol, certificaciones, manuales ni contenidos funcionales.

Sí fija una regla de seguridad transversal para Academia y manuales:

- nunca mostrar contraseñas generadas, calculadas o almacenadas;
- referirse a ellas como credencial inicial protegida;
- no incluir valores reales o de ejemplo que enseñen patrones de contraseña;
- cualquier captura futura del registro Shopper debe mostrar `Protegida` o equivalente.

## Estado

La corrección está preparada en V7.2-P0F1 y pendiente de reauditoría focalizada. No se actualizan manuales ni cursos hasta el freeze canónico.
